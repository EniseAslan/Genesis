# Genesis Web Projesi

Genesis, yaratıcı ajanslar, portföy siteleri veya kurumsal firmalar için geliştirilmiş, tamamen duyarlı (responsive) bir web temasıdır. Modern tasarım anlayışıyla hazırlanan bu proje, HTML, CSS ve JavaScript ile oluşturulmuş olup, kullanıcı deneyimini artırmak amacıyla çeşitli kütüphaneler entegre edilmiştir.

## Proje Özellikleri

- **Duyarlı Tasarım:** Tüm ekran boyutlarına uyumlu grid ve esnek yapı.
- **Mobil Navigasyon:** Küçük ekranlarda hamburger menü ile gezinme.
- **Servis Slider’ı:** Ok tuşlarıyla yönetilebilen, üç slayttan oluşan içerik döngüsü.
- **Kaydırma Animasyonları:** ScrollReveal ile elementlerin ekrana gelirken yumuşak geçişleri.
- **Galeri / Lightbox:** Fancybox ile portföy görsellerinin büyütülerek incelenmesi.
- **İkon Kullanımı:** Font Awesome üzerinden sosyal medya ve arayüz ikonları.
- **Kolay Özelleştirme:** CSS değişkenleri ile renk ve tipografi düzenlemeleri merkezî olarak yapılabilir.

## Kullanılan Teknolojiler

- HTML5
- CSS3 (Flexbox, Grid, animasyonlar, medya sorguları)
- JavaScript (ES6)
- ScrollReveal (kaydırma animasyonları)
- Fancybox (lightbox galeri)
- Font Awesome (ikon kütüphanesi)
- Google Fonts (Raleway ve Roboto)
